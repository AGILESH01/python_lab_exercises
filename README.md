# Python Lab Exercises

A collection of Python lab exercises and corresponding program outputs covering fundamental and intermediate Python programming concepts.

The files ending with `output.py` contain the output records showing the execution results, errors encountered, and iterations taken to achieve the correct code.

## Contents

- **Exercises 1 - 16**: Python scripts covering core programming topics (basics, calculators, geometric computations, string manipulations, dictionaries, file handling, logs, payroll processing, etc.)
- **Exercise Outputs**: Recorded outputs for each exercise (`Exercise * output.py`)
- **Supporting Data Files**:
  - `payroll.csv`
  - `students.txt`
  - `student.txt.rtf`
  - `system.log`
